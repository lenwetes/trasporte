# 📄 Centro Unificado de Gestión Documental del Conductor

Este nuevo módulo permite gestionar de manera integral toda la documentación legal y operativa de los conductores de la flota.

## 🚀 Características Principales

- **Dashboard Unificado**: Visualización clara de documentos obligatorios y su estado.
- **Validación de Vigencia**: El sistema marca automáticamente los documentos vencidos en color rojo con alertas visuales.
- **Historial de Documentos**: Permite consultar versiones anteriores de cualquier documento cargado.
- **Integración Multimódulo**: Resume el estado de licencias de conducción y exámenes de salud ocupacional en una sola vista.
- **Subida Simplificada**: Interfaz intuitiva tipo "drag & drop" (o clic) para cargar PDFs e imágenes.

## 📁 Documentos Gestionados

1. **Identificación**: Cédula de Ciudadanía.
2. **Antecedentes**: Policía, Procuraduría y Contraloría (requisitos legales para FUEC).
3. **Seguridad Social**: Comprobantes de EPS, ARL y Fondos.
4. **Capacitación**: Cursos de seguridad vial y otros certificados adicionales.

## 🛠️ Instrucciones para el Administrador

1. Navegar al perfil del conductor.
2. Ir a la pestaña **"Documentos"**.
3. Los documentos faltantes se mostrarán con un borde punteado.
4. Para actualizar un documento, haga clic en **"Actualizar"** o **"Renovar"**.
5. Para consultar versiones antiguas, haga clic en el icono de **"Reloj"** (Historial).
